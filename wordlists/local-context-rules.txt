# Local context-rule delta for movie-scrubber -- exemptions specific to this project that
# aren't part of the universal_game_editor shared baseline (religious-context-rules.txt).
# Merged ON TOP of that file (mirrors UGE's shared-baseline + per-game-delta pattern), so
# these survive untouched when the shared file gets re-vendored from upstream. Same
# <token>\t<context-regex> format. Optional: scrub/wordlists.py skips this file if absent.

# "hellfire" / "hell-fire" / "hell fire" -- common idiom ("hellfire and brimstone") and
# proper-noun usage (e.g. a Hellfire missile), not a vain "hell" exclamation. Matches all
# three spacing variants. CAVEAT (verified 2026-07-27, applies to every rule in this engine,
# not just this one): the exemption check matches against the WHOLE line/segment text, not
# the specific occurrence, so a bare vain "hell" sharing a line/cue with a "hell fire" mention
# rides along and gets wrongly exempted too (e.g. "hell fire, go to hell" exempts BOTH hits).
# Narrow in practice (both phrases would need to land in the same subtitle cue or Whisper
# segment) but a real false-negative risk, not a hypothetical one.
hell	\bhell[\s\-]?fire\b

god	\bfor\s+i\s+am\s+your\s+god\b
god	\bturn(ed|ing)?\s+away\s+from\s+god\b

# "god complex" -- a common secular idiom/psychological term ("a serious god complex", "has a
# God complex"), never a vain exclamation (you cannot shout "God complex!" as blasphemy the way
# you can shout "God!" or "Jesus Christ!"). Same idiom-exemption class as "hellfire" above,
# including the SAME caveat: found exactly 2 occurrences in the 817-hit sweep (S05E07 #646,
# S05E08 #23), both this idiom, but the exemption check is whole-line, not occurrence-specific,
# so a punctuation-free run-on where a vain "god" happens to be immediately followed by the
# word "complex" on the same line/segment would also ride along and get wrongly exempted
# (verified: censor.permit("god", "oh my god complex situation") -> True). Narrow (needs that
# exact adjacency with no comma) but a real false-negative risk, not a hypothetical one --
# Whisper transcripts in particular often lack the comma that would otherwise block this.
god	\bgod\s+complex\b

# "God has a plan" -- operator-directed exemption, 2026-08-05 (see note above): a testimony/
# faith idiom ("I know God has a plan…", S04E05 #616), same shape as the shared baseline's
# existing "Thanksgiving / testimony" category (\bgod\s+(gave|helped|answered|...)\b in
# religious-context-rules.txt) -- that list just doesn't happen to include "has a plan".
# Verified against the full 817-hit sweep: exactly 1 occurrence in the corpus, no collision
# with a vain/sarcastic use of the same phrase found.
god	\bgod\s+has\s+a\s+plan\b
